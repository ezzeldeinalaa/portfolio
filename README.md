# Ezz Eldein Alaa — Portfolio Website

A single-page personal portfolio for **Ezz Eldein Alaa Ahmed**, a Biochemistry undergraduate at Ain Shams University, built to showcase his academic background, experience, skills, certifications, and resume in an interactive, science-themed design.

🔗 **Fully coded by [Mahmoud Wael](https://github.com/)**

## ✨ Features

- **3D animated hero** — a rotating biochemical molecule rendered with Three.js that reacts to mouse movement and scroll
- **Dark "wet-lab" aesthetic** — custom color palette (bio-black, fluorescein green, bunsen-flame amber)
- **Scroll-reveal animations** using IntersectionObserver
- **Sections**: About, Education (with animated GPA ring), Experience timeline, Skills, Certifications, embedded CV viewer (PDF modal), and Contact
- **Fully responsive** layout built on Bootstrap 5
- **Custom cursor glow** and ambient canvas backdrop for an immersive feel

## 🛠️ Built With

- HTML5, CSS3, JavaScript (vanilla)
- [Bootstrap 5.3](https://getbootstrap.com/)
- [Three.js](https://threejs.org/) (r128) — 3D molecule animation
- [Font Awesome 6](https://fontawesome.com/) — icons
- Google Fonts: Space Grotesk, Fraunces, JetBrains Mono

## 🚀 Getting Started

Clone the repo and open `index.html` in your browser — no build step or dependencies required:

```bash
git clone <repo-url>
cd <repo-folder>
open index.html   # or just double-click the file
```
